# Python Expense Tracker

A simple Python-based Personal Expense Tracker that helps users manage their daily expenses.

## Features

- Add expenses
- View all expenses
- Calculate total spending
- Delete expenses
- Save expenses using CSV
- Load saved expenses when the program starts

## Technologies Used

- Python
- CSV File Handling

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

python expense_tracker.py

## Project Purpose

This project was created to practice Python programming, file handling, functions, loops, and basic data management.
